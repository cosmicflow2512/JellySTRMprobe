Trickplay

Jellyfin never generates trickplay for STRM items — its resolver marks them as shortcuts and the trickplay generator rejects shortcuts outright. The Generate STRM Trickplay scheduled task does it anyway. It needs media info, so run Probe STRM Media Info first.

Off by default. Generating trickplay streams every file in full, so a run takes a long time and moves a lot of data through your provider. While this is off, the task is hidden from Scheduled Tasks and will not run.

To speed it up, adjust Dashboard > Playback > Trickplay: enable Extract keyframes only (biggest win), keep a single width resolution (each extra width is another full pass over the file), raise the interval, and enable hardware acceleration if you have it.
Trickplay extraction streams each file in full. This limit keeps an accidental run from pulling the entire library through your provider.
